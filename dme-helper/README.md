# DME Helper

Сборка: запустите `build.bat` (нужен Python 3.10+ с галочкой "Add to PATH").
Готовый файл: `dist\DMEHelper.exe` — один файл, остальные не нужны.

Требования для запуска exe: Windows 10/11 + Microsoft Edge WebView2 Runtime
(есть в Windows 11 и большинстве Windows 10) и интернет (погода, IVAO, карта, шрифты).

Логбук и избранные аэропорты хранятся в `%LOCALAPPDATA%\DMEHelper`.
